Quero que você construa, neste diretório, uma aplicação local completa para gerenciamento e envio de campanhas pelo WhatsApp Web.

Objetivo

Criar uma aplicação que rode no meu próprio computador e tenha:

Importação de contatos por CSV.

Campo para mensagem da campanha.

Upload de uma imagem do produto.

Personalização da mensagem usando o nome do contato.

Pré-visualização da mensagem.

Teste de envio para um único contato antes da campanha.

Execução da campanha pelo WhatsApp Web.

Controle de iniciar, pausar e cancelar.

Registro detalhado dos resultados.

Detecção e tratamento de erros.

Interface visual simples e profissional.

Nenhum backend em nuvem.

Nenhum banco de dados externo.

Nenhuma API paga.

Dados e logs armazenados localmente.

A aplicação deve ser projetada para uso legítimo com contatos que deram consentimento para receber comunicações.

Não implemente mecanismos para:

burlar CAPTCHA;

burlar bloqueios do WhatsApp;

ocultar automação;

contornar limites ou sistemas anti-spam;

criar contas automaticamente;

enviar para números aleatórios obtidos sem consentimento;

tentar evitar detecção da automação.

Se o WhatsApp Web mudar e uma determinada automação deixar de funcionar, registre o erro de forma clara em vez de tentar contornar as proteções.

Use:

Node.js

TypeScript

Playwright para automação do navegador

React para a interface

Vite

Tailwind CSS

Electron para transformar a aplicação em desktop

Zod para validação

Papa Parse ou biblioteca equivalente para CSV

Vitest para testes

Evite dependências desnecessárias.

A aplicação deve funcionar localmente em Windows, macOS e Linux sempre que possível.

Formato dos contatos

Aceite CSV com:

nome,telefone

Exemplo:

nome,telefone
João,5511999999999
Maria,5511988888888
Carlos,5511977777777

Também aceite CSV sem nome:

telefone
5511999999999
5511988888888

Normalize os números.

Para o Brasil, aceite formatos como:

11999999999
5511999999999
+5511999999999
(11) 99999-9999

Converta internamente para um formato consistente.

Não tente descobrir números ou coletar números da internet.

permitir exportar a lista limpa.

Não declarar que um número possui WhatsApp apenas porque passou pela validação sintática.

WhatsApp Web

Usar Playwright.

Abrir uma instância persistente do navegador para que a sessão do WhatsApp Web possa permanecer autenticada localmente.

Na primeira execução:

Abrir WhatsApp Web.

Aguardar o usuário fazer login normalmente.

Não tentar capturar ou armazenar credenciais.

Reutilizar a sessão local nas próximas execuções.

Não implementar login automático.

Não armazenar QR codes, tokens ou credenciais em servidores.

Automação

Criar um módulo:

whatsappService.ts

Com uma interface semelhante a:

interface WhatsAppService {
connect(): Promise<void>;
isConnected(): Promise<boolean>;
sendMessage(contact: Contact, message: string, imagePath?: string): Promise<SendResult>;
disconnect(): Promise<void>;
}

A lógica da campanha NÃO deve depender diretamente do Playwright.

Use uma camada de abstração para facilitar testes.

Pausa

Quando o usuário clicar em "Pausar":

não iniciar novos envios;

terminar de forma segura a operação atual;

marcar campanha como PAUSED.

Ao clicar em continuar:

continuar do próximo contato pendente.

Cancelamento

Ao clicar em cancelar:

interromper o processamento depois que a operação atual terminar de forma segura;

não iniciar novos contatos;

salvar estado da campanha.

Respeito ao usuário

Adicionar na interface uma configuração:

"Somente enviar para contatos que autorizaram receber mensagens."

Ela deve ficar marcada por padrão.

Também adicionar suporte a uma coluna opcional:

optIn

Exemplo:

nome,telefone,optIn
João,5511999999999,true
Maria,5511988888888,false

Por padrão, somente:

optIn=true

pode ser enviado.

Se a coluna não existir, mostrar um aviso informando que o usuário precisa confirmar que todos os contatos possuem autorização antes de iniciar.

Não inventar consentimento.

Adicionar arquivo local:

Adicionar uma opção para marcar um contato como "não enviar novamente".

Nunca remover automaticamente um contato da lista de bloqueio.
